# Winget Updater – verwendete Bildprompts

Modus: integriertes `image_gen`, fünf unabhängige Generierungen, keine Referenzbilder, kein transparenter Hintergrund.

Jeder tatsächlich verwendete Prompt besteht aus der gemeinsamen Vorgabe und dem jeweiligen Konzeptabschnitt.

## Gemeinsame Vorgabe

```text
Use case: logo-brand.
Asset type: professional brand concept presentation for the existing application "Winget Updater".
Create ONE beautiful carefully composed landscape branding concept board, aspect 3:2, high resolution. This is one of five independent directions, not five logos in this image.
Product truth: an independent Windows desktop/tray app for scanning and automatically updating software across winget, Scoop, Chocolatey, npm and pip. Audience: people who want their Windows software maintained with clear control and little effort. Personality: useful, reliable, quiet, precise. The name remains EXACTLY "Winget Updater". Do not add a version number.
BOARD LAYOUT: clean studio identity sheet with carefully aligned 2-column top region and one full-width lower README banner region; generous gutters and outer margin. Top-left: large 3D-free square app icon with smoothly rounded corners and the original logo, plus a small detached flat monochrome version of the same glyph. Top-right: wordmark "Winget Updater" in large clean Geist-like sans-serif, tiny concept number/name label, three solid color swatches with precise hexadecimal labels, and small 16px/24px/32px monochrome tray-style samples of the exact same silhouette. Bottom full-width: a wide, fully designed README header/banner with the EXACT same glyph and name, one short tagline, calm branded graphic motif. Banner should be a real complete rectangular design, with no device mockup or browser frame. The banner is the second focal point after the app icon.
Keep the exact same symbol geometry across the app icon, monochrome logo, size samples, and banner. Crisp vector-friendly flat shapes, professional original logo system, sophisticated proportion, restrained surfaces. Minimal readable type, no paragraphs, no pseudo-UI, no screenshots, no photos, no certificates, no shirts, no business cards. No watermarks or third-party marks. Avoid generic template collage, excessive rounded card containers, excessive texture, neon, glow, glass bevels, copied corporate logos. At most one subtle matte surface shadow under the app tile. Allow large empty areas.

```
