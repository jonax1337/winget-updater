## What's new

### One administrator approval per app session

WinGet and Chocolatey installations, updates, and removals now use a session-scoped administrator helper. Approve the standard Windows UAC prompt once, then subsequent system operations reuse that approval until you quit Winget Updater.

The interface and user-scoped package managers (Scoop, npm, and pip) remain unelevated when the app is launched normally. No Windows service or scheduled task is installed.

### Request access at startup

**Settings → Administrator access → Request administrator access at startup** is enabled by default, including for existing settings. The app requests approval when it starts, including when launched by Windows autostart, before scheduled update runs begin.

- Turn the setting off to defer approval until a manual system operation or use **Authorize session** in Settings.
- **Active for this session** shows when access is available; **End access** revokes it.
- Closing the window to the tray keeps the session alive. Fully quitting the app ends access.
- Declining startup approval does not trigger repeated UAC prompts from scheduled updates. User-scoped updates can still run; system updates need you to authorize the session.

### WSL and other system updates

The app now runs WinGet system operations with administrator rights after approval, addressing failures caused by missing elevation, including Windows Subsystem for Linux (`Microsoft.WSL`).

## Important limitations

- Administrator rights do not unlock files held by other programs. For example, OBS updates may still require closing Edge, Teams, or another application using its virtual camera.
- Approval must use the same Windows account that launched the app. Elevating with a different administrator account is not supported.
- A disconnected helper is not used to automatically replay an installation. Check the installed version before retrying if the operation's result is uncertain.
- Automated tests and build checks passed. The real Windows UAC/sign-in flow and an elevated WSL update have not yet been manually verified.
